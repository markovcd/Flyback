Plugins

Submit a plugin.

Pack it with flyback-cli pack-plugin --key and send the .fbkp. It is listed once it has been reviewed.

Said by the plugin

The name, version, author and description come from the plugin assembly's own metadata: <Product>, <Version>, <Authors> and <Description> in its project. What it adds and what it reaches are read from its code. The site runs none of it, and refuses a package the editor would refuse.
