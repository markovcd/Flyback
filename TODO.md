- **A spending limit the host keeps.** Count each assistant session's requests in the transport and stop past a bound, and add up the token use `ModelReply` reports against a daily budget the user sets in Settings → Assistant, so a runaway or buggy plugin cannot spend without end. Until then a Line In is silent there and says so.
